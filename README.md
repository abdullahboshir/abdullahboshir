## Current work

**Signature Bangla** (2025 – present) · [signaturebangla.com](https://signaturebangla.com)
Online grocery store with a Next.js storefront, a NestJS and PostgreSQL backend, and a React admin dashboard. I wrote the original requirements, took the codebase over in July 2026, finished it and now run it in production.

**Manoxen** (private, my own product)
An ERP and POS platform for multi-branch businesses: POS, inventory, sales, accounting, HR and CRM in one Turborepo monorepo. Each business's data is kept separate, and staff permissions are set per organization, business unit and outlet. Built with Next.js, Express.js, MongoDB and Redis.

**AI sales chatbot** (part of Manoxen)
A chatbot for Messenger and web chat that can search products, check order status and cancel orders for customers. It works with OpenAI and Google Gemini and switches provider if one fails.

**Banijjik** (private, in development)
A business management SaaS for many industries: shops, salons, gyms, coaching centres and clinics. It covers orders, bookings, enrollments, POS, bookkeeping and a website builder, and a new industry is added by configuration instead of new code. Built with Next.js, Express.js, MongoDB and Redis.
